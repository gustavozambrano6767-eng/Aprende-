APRENDE+

APRENDE+ es una plataforma web educativa desarrollada para apoyar el aprendizaje mediante evaluaciones, seguimiento del progreso académico e inteligencia artificial.

## Funcionalidades

* Registro e inicio de sesión de usuarios.
* Gestión de cursos y contenidos educativos.
* Evaluaciones y calificación automática.
* Seguimiento del progreso académico.
* Tutor virtual basado en Google Gemini AI.
* Recomendaciones de estudio personalizadas.
* Panel administrativo para gestionar usuarios, cursos y resultados.

Tecnologías

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript
* Google Gemini API
* Bootstrap

Inteligencia Artificial

La plataforma integra Google Gemini para ofrecer un tutor virtual capaz de responder preguntas y brindar apoyo al estudiante según sus necesidades de aprendizaje.

Objetivo

APRENDE+ busca combinar educación e inteligencia artificial para ofrecer una experiencia de aprendizaje más personalizada, permitiendo a los estudiantes consultar contenidos, realizar evaluaciones y conocer su progreso académico.
